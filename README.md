# Sonsuz Bekleme Odası

## Dünyanın En Gerçekçi Devlet Dairesi Simülatörü

Bu proje, Türkiye'nin en kutsal kurumsal deneyimini dijital çağa taşır: **SONSUZ BEKLEME**.

Hiçbir şey olmaz. Sıra gelmez. Numara çağrılmaz. Sadece beklenir. Ve beklenir. Ve beklenir...

### Özellikler
- Gerçek zamanlı bekleme hissi
- Rastgele "numara çağrılıyor ama senin değil" mesajları
- Felsefi derinlik: "Acaba bu sıra gerçekten var mı?"
- %100 Türkçe, %0 verimlilik
- Gizli bir şey yok. Kesinlikle yok.

### Kullanım
```bash
python bekleme_odasi.py
```

Sonra otur ve bekle. Sonsuza kadar. Gerçek hayat gibi.

### Neden Bu Proje?
Çünkü bazen en büyük inovasyon, hiçbir şey yapmamaktır. Bu kod, modern teknolojinin zirvesidir: **hiçbir işe yaramayan mükemmel bir simülasyon**.
